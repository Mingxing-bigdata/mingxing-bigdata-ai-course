一分钟掌握 Agent Skill

看完卡片约 60 秒 → 滑到底部自测 5 题
⏱ 目标用时：1 分钟阅读 + 2 分钟测试

1 Agent（智能体）是什么？

Agent = 能“感知目标 → 自主规划 → 调用工具 → 完成任务”的 AI 系统
🧠 大脑大语言模型：理解意图、生成决策
📋 规划把大任务拆成小步骤，逐步执行
🔧 工具能调用外部能力：搜索、写文件、执行命令、发请求
🗂 记忆记住上下文与结果，持续修正

一句话记忆：Agent = LLM + 规划 + 记忆 + 工具

2 Skill（技能）是什么？

Skill 是给 Agent 预装好的「专项能力包 / 操作手册」

当任务匹配某个 Skill 时，Agent 就按这份手册行动，不用每次重新发明流程。 打个比方：Skill 之于 Agent，就像 SOP 之于新员工，插件之于浏览器。

📄 SKILL.md技能说明书：name 技能名、description 何时该用、正文写清楚操作步骤与规范
📁 scripts/可执行的辅助脚本（Python/Shell 等），把重复劳动自动化
✨ 价值结果稳定、开箱即用、知识沉淀、可复用可分享
🎯 关键description 写得越具体，Agent 越能在正确时机调用它

3 一次典型工作流程

用户提出任务“做一份周报”
→
Agent 理解意图LLM 推理
→
匹配 Skill读 description
→
加载手册并执行步骤+脚本+工具
→
交付结果反馈给用户

核心逻辑：“会用的工具” 与 “会做事的方法” 分离 —— 方法沉淀在 Skill 里，人人都能共享。

💾 60 秒记忆卡（考前只看这里）

  1. Agent 四要素 = 大脑(LLM) + 规划 + 记忆 + 工具
  2. Skill = 给 Agent 的“专项能力包”，核心是 SKILL.md（元信息+操作手册）+ scripts（脚本）
  3. description 决定触发：写清“什么场景/什么任务”用，Agent 才能对号入座
  4. Skill 的意义：把高质量做事流程沉淀为可复用资产，让 Agent 稳定、专业、可分享

5 自测题（5 题 · 约 2 分钟）

Q1 · 单选题
以下哪一项不属于 Agent 的核心组成？
Agent = LLM + 规划 + 记忆 + 工具，与硬件型号无关。故选 B。
Q2 · 单选题
一个 Skill 的“说明书”文件通常叫什么？
习惯约定为 C. SKILL.md：内含 name、description（何时该用）与正文操作步骤。
Q3 · 单选题
Skill 的 description 写得模糊，最可能发生什么？
A。description 是 Agent “对号入座”的依据——越具体，触发越准确。
Q4 · 判断题
“Skill 中的 scripts 脚本可有可无，Skills 只能写成纯文字说明。”
B. 错误。纯文档的 Skill 也成立，但配上 scripts/ 脚本能把重复步骤自动化，能力大大增强。
Q5 · 简答题（口头说出即可）
用你自己的话解释：Skill 给 Agent 带来的最大价值是什么？
参考要点：① 把“高质量做事流程”沉淀下来，Agent 开箱即用、结果稳定；② 知识可复用、可分享（团队/社区）；③ 让通用 Agent 具备“专项专家”能力，无需重复造轮子。
得分：-- / 4（客观题）
